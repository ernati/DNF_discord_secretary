결과 코드 정보
응답 코드
REST API 호출을 통해 HTTP의 상태 코드 및 실행 결과에 따른 다양한 에러 코드가 존재합니다.
응답 코드에 대해서는 상황에 따라서 변경될 수 있습니다.


HTTP 상태 코드
응답에 대한 HTTP 상태 코드입니다.

HTTP 상태 코드	설명
200	정상적인 응답
400	요청에 대한 유효성 검증 실패 또는 필수 파라미터 에러
401	인증 오류
404	존재하지 않은 리소스 또는 페이지
500	시스템 오류
503	시스템 점검
